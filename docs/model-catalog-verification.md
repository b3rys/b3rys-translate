## 재현

```sh
npx wxt prepare
npx vitest run
npm run lint
npm run typecheck
npm run format:check
npm run build
python3 scripts/check-model-catalog-mutants.py
```

뮤턴트 스크립트는 임시 사본에만 결함을 넣는다. 치환 대상·실제 적용·테스트 실패·원복을
확인하며 원본 작업 트리는 변경하지 않는다. 기본 실패 0개, 각 뮤턴트 실패 1개,
원복 실패 0개다. 전체 자동 테스트는 40개 파일, 482개 검사다.
기존 테스트 리포터의 lint 경고 8개는 남아 있으며 오류는 없다.

실제 Chrome 확인 경로는 확장 팝업 → 모델 선택 메뉴와 모델 가격 툴팁이다.
기존 다섯 라벨, 엔진별 저장 선택, 가격 표가 유지되는지 확인한다.
이번 PR에서 원격 권한·호스트·요청 옵션은 변경하지 않는다.
롤백은 이 PR의 커밋을 되돌리고 다시 빌드한다. 저장소 형식의 마이그레이션은 없다.
